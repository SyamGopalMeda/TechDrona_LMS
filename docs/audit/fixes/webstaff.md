# Fixes — webstaff (staff portals web UI)

Agent key `webstaff`. Owned paths: `apps/web/src/app/{admin,security,desk,studio,finance,trainer,college,mentor}/**`, the matching `apps/web/src/features/*` directories, the new `features/staff-portal/`, and new staff e2e specs. Nothing was committed or pushed. No DB or docker was touched. The work was split across sub-agents by portal, and the lead integrated and verified it.

Before building, the web OpenAPI copy and types were regenerated from the current api, which includes the commerce, secadmin and assess backend fixes. Steps: `python -m app.scripts.export_openapi` (apps/api venv), then copy `apps/api/openapi.json` to `apps/web/openapi/openapi.json`, then `npm run gen:api`.

Reproduction method: each fix has a vitest regression test, written next to the feature, that fails against the old code. Typical failures it catches: a `NotImplemented` page, a missing call, a wrong request body, or a missing cursor. The e2e specs are gated by `@integration` / `E2E_INTEGRATION` and were **not run**, because no seeded stack with staff credentials was available.
